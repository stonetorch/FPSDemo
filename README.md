# FPSDemo - 多人第一人称射击游戏

## 项目简介

这是一个基于 Unreal Engine 5.2 开发的多人第一人称射击游戏项目，用于线上课程作业。

## 项目实现的功能

- **多人网络对战**：支持多玩家同时在线，新加入的玩家会自动均等分配到红队或蓝队
- **角色移动与战斗**：流畅的角色控制，支持移动、跳跃、视角控制，以及攻击和击败敌方角色
- **得分与胜利系统**：团队得分实时显示，当一方得分达到5分时游戏结束
- **AI敌人系统**：AI敌人会自动攻击玩家，参与团队对战
- **完整武器系统**：多种武器类型，支持开火、后坐力、武器切换等功能


## 玩法介绍

游戏实现了一个简单的玩法逻辑，角色（包括玩家和AI）被分配到红队和蓝队，每个队伍有不同的得分，击杀敌方队伍的玩家可以得分，在一方得分达到5分时游戏结束。玩家所在的队伍和当前得分情况可以在屏幕上方看到。

## 操作说明

- 移动：W、A、S、D
- 开火：鼠标左键
- 切换武器：1、2、3键或鼠标滚轮
- 设置菜单与简要说明：Esc

## 环境

Unreal Engine 5.2.1

## 注意事项

1. 需要使用“网络模式:以客户端运行”，否则部分功能无法正常使用
